# Fortune Cookie for the Liquidated Trader

One line: a fortune cookie for a trader who has just been liquidated. It opens in the classic oracular voice — great wealth, where you'd never think to look — and the punchline turns the fortune back on the reader: the wealth is sitting in the wallet he just emptied.
